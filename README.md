# 人類史ハードモード（仮称）— 第1章「黒死病 — 1348年、イタリア」

もし自分が、人類史上最も過酷な時代に生まれていたら、生き延びることができるのか？

スマートフォンのブラウザで遊べる、3D一人称視点の歴史サバイバル・シミュレーションです。
プレイヤーは英雄ではなく、トスカーナの丘の町カステルヴェント（架空）に暮らす毛織物職人。妻ルチア、八つの息子マルコとともに、黒死病が広がる14日間を生き延びることを目指します。1プレイ10〜15分ほど。

## 起動方法

```sh
npm install
npm run dev        # 開発サーバー（同じLANのスマホからも http://<PCのIP>:5173/ で開ける）
npm run build      # 型チェック＋本番ビルド（dist/）
npm run preview    # ビルド結果を確認
npm test           # ゲームロジックの自動テスト
npm run balance    # 自動プレイによる結末の分布（戦略ごとに200回）
```

`dist/` は相対パスでビルドされるので、GitHub Pages などの静的ホスティングにそのまま置けます。

## 基本ルール

- 朝は自宅から。1日に使える時間は **6刻**。歩くだけでは減らず、「働く（3刻）」「買い物（その日最初の1回に1刻）」「看病（2刻）」などの行動で減ります。すべてはできません。
- 工房のグイド親方のもとで働いて稼ぎ、市場で食料を買う。食料は毎晩、家族の人数ぶん減ります。足りない夜は、誰に食べさせるかを選びます。
- 自宅の **寝床** を調べると夕食をとって一日が終わり、夜の処理（空腹・病の進行・家のネズミ・出来事）が行われます。
- 感染リスクは画面に出ません。噂、家の様子（かじられた袋、ノミ）、家族の言葉から推し量ります。
- 町は日を追って「日常 → 異変 → 流行 → 崩壊」へ変わります。人通りが減り、露店が消え、戸が板で打たれ、市場が閉じ、門が閉ざされ、物価が上がります。変化の時期と速さは毎回変わります。
- 14日目の夜を越えるか、あなたが死ぬか、町を出ると結末へ。

## 主なイベント

- **家族**：朝の会話（状況と過去の出来事で変わる）、ルチアへの相談、マルコと遊ぶ、黒猫を飼う、蜂蜜の菓子、外で遊ばせるか、うなされる夜、言い争い、形見の指輪、かまどの前の約束、発症・看病・回復・死と弔い
- **町**：船乗りの噂、評議会の触れ（ピストイアの条例が下敷き）、まとめ売り、隣人テレーザの発病と看病、石工ピエトロの頼みと返礼（手押し車・通用門）、孤児ピッポ、よそ者への疑い（かばうと後で行商人が助けてくれる）、贖罪の行列、医師のテリアカ、空き家の物色、亡骸を運ぶ仕事、夜の盗人、市場の閉鎖とベッペの裏口、閉ざされた門
- **避難**：ルチアの同意、門が開いているうち／門番への賄賂／ピエトロに教わった通用門。道中の食料、病人の有無、手押し車、町の外の情報で結果が変わり、逃げた先にも病はあり得ます。家族を置いてひとりで逃げることもできます。

## エンディング

| | 条件 |
|---|---|
| A | あなたと家族全員が生存（町に残る／避難先で） |
| B | あなたと家族の一部が生存 |
| C | あなただけが生存（家族を置いて逃げた場合も） |
| D | あなたは死んだが、家族の誰かが生き残った |
| E | 全員が死亡 |

リザルトでは、短い物語、生存日数、家族の生死、最終所持金と食料、主な選択、最も危険だった出来事、感染の原因の推定などの振り返り、そして「史実／研究・推定／創作」を区別した歴史解説を表示します。

## 感染モデル（現代の知識にもとづく単純化）

登場人物は病の正体を知りませんが、内部では次のように扱っています。

- **腺ペスト**：ネズミとノミ（およびヒトノミ・シラミ）が主な経路。家のネズミの多さ（食料の溜め込みで増え、掃除・洗濯・猫で減る）と町の流行度で、毎晩リスクが積み上がる。病人の寝具、死者の家の物、亡骸運びも危険。
- **肺ペスト**：咳の飛沫で人から人へ。患者のそばでの看病や人混みが危険で、致死率がきわめて高い。
- 病人と会話しただけでは感染しません。リスクには個人差のあるしきい値があり、超えると潜伏期（2〜4日、肺ペストは1〜2日）を経て発症します。
- 発症後は食事・看病・生活用品が体力の減り方を左右し、峠（4〜5日）を越えれば回復して免疫を得ます。薬草は苦痛を和らげる程度、テリアカは効きません（当時の治療観として登場）。

## 構成

```
src/
  core/         シリーズ共通（型、乱数、イベントエンジン、シナリオの約束事、セーブ）
  scenarios/
    blackdeath/ 黒死病編（ルール、町の地図、配役、会話とイベントのデータ、リザルト）
  three/        3D表示（町の組み立て、人物モデル、質感、操作、カメラと当たり判定）
  ui/           React の画面（タイトル、HUD、会話、店、メニュー、リザルト）
  store.ts      画面の状態（zustand）
  audio.ts      WebAudio で合成した音
tests/          ロジックの自動テストと、自動プレイのボット
```

- ゲームロジックは3Dに依存せず、`GameState` を書き換える純粋な関数です（自動テストは3Dなしで最後まで遊べます）。
- 3D側はシナリオの `worldView()` が返す「いまの町の見え方」を映すだけです。
- イベント・会話は `scenarios/blackdeath/content/` のデータ（条件・選択肢・結果）で、自動発生の条件（いつ・どこで・一度きりか・間隔）も各イベントに持たせています。
- 新しい時代は `Scenario` インターフェース（`src/core/scenario.ts`）を実装し、固有の状態を `GameState.sc` に持たせます。黒死病の感染ルールは `blackdeath/rules.ts` の中だけにあります。
- 人物モデルは `three/characters.ts`、質感は `three/textures.ts`（画像なし）、見た目の配役は `blackdeath/cast.ts` で差し替えられます。

## 歴史について

町と人物は架空です。ピサ・ルッカからの入市禁止や古着の売買禁止などの触れ書きは1348年のピストイアの条例、遺体運び（ベッキーニ）や富裕層の逃避はボッカッチョ『デカメロン』の記述を下敷きにしています。死亡率の推計や媒介の役割（ネズミのノミか、ヒトノミ・シラミか）には研究上の議論があり、ゲーム内の解説ではその旨を区別しています。
